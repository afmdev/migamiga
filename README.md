# MIGAMIGA

Static site for [migamiga.berlin](https://migamiga.berlin) — a Berlin sandwich catering business
(office lunch boxes, event catering, pop-ups). Plain HTML, CSS and JS: no framework, no bundler,
no install step. The four language versions are generated from the English source pages.

## Layout

```
index.html                 redirect to /de/ (x-default)
about.html  faq.html  404.html   English source pages — edit these, not de/en/es/it
de/ en/ es/ it/            generated: index.html, about.html, faq.html, 404.html
css/                       style.css + vendor plugins
js/                        main.js + vendor plugins
img/  fonts/
scripts/build_i18n.py      page generator
scripts/i18n/<lang>.txt    translations, one "id|text" per line
sitemap.xml                generated by the script
robots.txt  llms.txt  llms-full.txt
```

## Editing content

Edit the English source page at the root, then regenerate:

```bash
python3 scripts/build_i18n.py           # rebuild de/ en/ es/ it/ and sitemap.xml
python3 scripts/build_i18n.py --dump    # append new English strings to scripts/i18n/en.txt
python3 scripts/build_i18n.py -v        # list the missing keys per language
```

`en.txt` is append-only and holds `id|english`; each `<lang>.txt` holds `id|translation` for the
same ids. Lookup is by the whitespace-collapsed English string, covering text nodes, `alt`,
`aria-label`, `title`, `content` and JSON-LD values. Anything matching the `KEEP` pattern (names,
emails, URLs, image paths, product names) is left untranslated, and missing keys fall back to
English. The script also rewrites canonical/`hreflang`/`og:` tags and the language switcher.

Per-language URL slugs live in `PAGES` in the script (`about` → `ueber-uns`, `nosotros`,
`chi-siamo`) and drive the canonical URLs and the sitemap.

## Preview

```bash
python3 -m http.server 8000     # then open http://localhost:8000/de/
```

Pages also work opened directly via `file://` — all asset paths are relative.

## Deploy

Static hosting; serve the repository root as-is. `index.html` redirects to `/de/`.
